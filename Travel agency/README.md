# Jadoo - Travel Agency Landing Page

A React + TypeScript + Tailwind CSS implementation of the Jadoo Travel Agency web application design.

## Features & Highlights

- **Pixel-Accurate Design**: Faithfully translates the Figma landing page design, including typography (`Volkhov` serif headings and `Poppins` sans-serif body), exact color palette (`#DF6951`, `#F1A501`, `#181E4B`, `#5E6282`), signature decorative flourishes, and ambient gradients.
- **Hero Section**:
  - Distinctive orange brush underline stroke on "enjoy"
  - Stylized traveler composition with floating flight trajectory airplanes
  - "Find out more" CTA and "Play Demo" modal trigger
- **Services ("We Offer Best Services")**:
  - 4 featured service cards: *Calculated Weather*, *Best Flights*, *Local Events*, *Customization*
  - Active card backing card offset in signature coral/orange
  - Decorative dot grid accent
- **Top Destinations**:
  - Dynamic cards for *Rome, Italy*, *London, UK*, and *Full Europe*
  - Duration tags, price tags, and spring spiral decoration
- **Booking Steps**:
  - 3 easy steps with custom color-coded badges
  - Layered Greece card with active trip details and interactive like toggle
  - Overlapping "Ongoing - Trip to Rome" card with live progress bar
- **Testimonials**:
  - Interactive slider with pagination dots
  - Stacked card perspective with floating user avatar
  - Up/Down review switcher
- **Partner Airlines**:
  - Grayscale to full-color hover transition for Axon, Jetstar, Expedia, Qantas, and Alitalia
- **Newsletter Subscription**:
  - Curved lavender card with floating paper airplane badge
  - Interactive email validation and success toast
- **Interactive Modals**:
  - Video preview modal for "Play Demo"
  - Instant trip booking reservation modal with destination selector and price estimate
  - Login / Sign up authentication modal

## Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
