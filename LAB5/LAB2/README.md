# LAB2 — React Resume App

## Overview
This is **LAB2** for the FSD Assignments (BCA Hons — RV University).

It is a **React-based personal resume web application** built by **Syed Yasir**.

## Features
- Hero header with avatar, name, title, and contact links
- Career Objective section
- Education section
- Skills section (Languages, Frameworks, Tools)
- Projects section
- Languages section
- Interests section

## Tech Stack
- **React 19** (Create React App)
- **Vanilla CSS** with Google Fonts (Inter)
- Responsive design with mobile support

## How to Run
```bash
# Install dependencies
npm install

# Start development server
npm start
```

The app will open at `http://localhost:3000`
