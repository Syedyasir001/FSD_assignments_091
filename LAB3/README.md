# LAB3 — Spotify Homepage Clone (React)

## Overview
This is **LAB3** for the FSD Assignments (BCA Hons — RV University).

It is a **React-based Spotify homepage clone** built by **Syed Yasir**, featuring the classic header, hero section, and multi-column footer layout.

## Features
- Sticky Spotify-style header with logo, navigation, and auth links
- Hero section with heading and tagline
- Full-width footer with company / communities / useful-links columns and social icons
- Vanilla CSS responsive layout

## Tech Stack
- **React 19** (Create React App)
- **Vanilla CSS**
- Inline SVG logo (no external assets)

## How to Run
```bash
# Install dependencies
npm install

# Start development server
npm start
```

The app will open at `http://localhost:3000`
